## Stack and Dictionary

Because Java has more explicitly defined data structures than Python, we start with one Java example. In Java, the equivalent structure is referred to as a `Map`, while Python uses a `dictionary`.

To run the Java example in terminal:

```bash
javac StackAndMap.java  # First, compile via javac(ompiler).
java StackAndMap        # Then, run.
```

Continue with:

```bash
stack_and_dictionary.ipynb
stack_and_dict_exercise.ipynb
```

The first notebook introduces the concepts and examples. The exercise notebook gives you a small task to work through yourself.

## Tree and Queue
Work through `queue_and_tree.ipynb`.

Run all relevant cells and study the examples for both queue and tree structures.

# What You Should Take Away

After completing these materials, you should be able to recognise the covered data structures, explain their basic behaviour, and reason about which structure is suitable for a given task.

Do not only read the notebooks. Run the code, modify small examples, and observe what changes.
